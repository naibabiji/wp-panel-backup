# 插件常见场景验收

只验证实际插件，不把 P1–P4 原型结果替代成品验收。不主动扩展强杀/全面并发/多重故障；PHP 改动先 php -l，测试后记录环境和结果即可。

## 首版主流程

1. 在本任务本地普通单站安装/启用插件，管理员可进入一个备份页，普通用户不能操作或下载。
2. 正常备份导出：包含自建目录/中文文档/空目录/零字节文件和数据库全部表；隐藏项按说明排除。
3. 用已确认精确规则检查缓存/备份两个类别开关，不误删名称类似的自建数据。
4. 检查一个超过 512 MiB 的单文件可分块分包，独立解包重组后大小/完整 SHA256 与源相等；其他正常文件逐一比对。
5. 全表 SQL 恢复到一次性测试库，表集合、结构/索引及数据比对相同；包含历史前缀、自建表和空表。不在真实源库执行恢复。
6. 临时维护正常完成可重新访问；搬家完成仍显示维护，取消备份不解除，明确取消搬家才恢复。复制材料不让目标继承控制状态。
7. 下载按完整材料展示，文字为已发起；关页不再推进，返回可按已确认边界继续；失败显示原因而非完整成功。

## 少量直接失败

不支持的布局/链接、必要读写失败、工作目录不可安全使用时有明确拒绝或失败；不生成虚假完整材料。只测与当次模块直接相关的常见情况。

本阶段不测试面板上传恢复、证书、DNS，不新增完整恢复器模拟这些功能。插件备份通过后，面板开发完成再做一次正常整站恢复验收。
