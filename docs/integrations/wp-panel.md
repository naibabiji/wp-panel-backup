# 与 WP Panel 的跨项目契约

- 本项目：/home/luanc/Projects/wp-plugins/wp-panel-backup，独立源站 PHP 插件。
- 对方：/home/luanc/Projects/go-panels/wp-panel，私有 Go/Gin/SQLite 面板。
- 对方记录：[面板侧集成文档](/home/luanc/Projects/go-panels/wp-panel/docs/integrations/wp-panel-backup.md)。
- 来源：用户 2026-11-22 明确先插件开发/实际备份验证，再面板恢复建站。

## 各自负责

| 本项目 | WP Panel 项目 |
| --- | --- |
| 源预检、全目录/全表导出、三模式、分包/哈希、进度/下载 | 接收/续传/校验、冲突拒绝、新站资源、完整输入恢复、目标配置/权限/身份、HTTPS |
| 记录源主域名/协议/活动前缀及排除范围 | 只读域名创建，不改域名、不覆盖原站，维持原 HTTPS |
| 管理源端维护/任务和源端备份材料 | 管理目标材料/失败结果，不解除源搬家维护 |

- 插件无需面板账号、root、SSH 或 mysql CLI。管理员可为已完成备份生成仅限该备份的读取链接，由面板逐包拉取。
- 不涉及 wp-panel-optimizer/Assistant，不写它们的项目，不自动复用其授权身份。
- 面板现有普通数据库恢复功能保持，新站恢复复用其 root/CLI 核心和原过滤；该决定不要求源插件开发安全 SQL parser。

## 格式和变更

[本项目 backup-format.md](../backup-format.md)记录随插件 1.0.0 首发冻结的 v1 格式。候选已通过真实备份下载及面板恢复建站验收，沿用原有 magic 和格式版本以兼容已生成的材料。

源站最低要求为 WordPress 6.5、PHP 7.0，源 WordPress 与 PHP 仍须相容。WP Panel 目标运行环境为 PHP 8.3。备份页只提示版本差异及恢复后的排查方法，继续使用原交换格式。旧站文件和数据库能导出，并不代表同一份站点代码能在目标 PHP 8.3 上运行。恢复后的健康检查及失败提示由面板负责。

格式、源配置依赖、状态隔离或兼容范围变化时，本项目先记录影响；需要修改另一项目时确认任务授权并分别更新任务卡。不能仅因为某项目可写就顺便改另一个项目的代码或 schema。已有 user 授权范围内的两侧文档同步无需重复确认。

## 交接给恢复开发

插件实际常见备份验证通过后提供：格式版本/字段说明、脱敏合成样本生成方法、文件/表集合与字节比对结果、排除/配置依赖/兼容说明。实际备份、数据库 dump、密码和 wp-config 不提交到仓库。

## 恢复链接

源站管理员对已完成备份生成可撤销的只读链接，最长 12 小时且受备份本身到期时间限制。新链接使旧链接失效。源端仅保存凭据摘要，经 HTTPS 根据凭据发送指定清单、索引或 ZIP。现有下载和交换格式沿用 v1。凭据放在可复制链接的片段中，面板使用请求头发送，凭据不进入归档。网站使用维护模式时，持有有效链接的面板仍可读取该备份的材料。撤销使后续请求失效，已打开的单个材料可传输完。
